Feature Showcase

Built different,
by design.

Every decision in NoctRemote was made to remove friction between your intent and the TV's response. Local-first. Always.

Zero Latency

Local WebSocket connections mean your command arrives at the TV before your finger leaves the button. No cloud roundtrip. No server latency. Pure, direct control.

<20ms
Typical local command latency

System-Level Control

The NoctRemote overlay lives as a floating glass surface inside the Android OS. Trigger it from your Quick Settings tile — no app-switching, no interruption. It's part of the OS, not a guest.

Procedural Discovery

mDNS scanning finds every TV on your network automatically — no manual IP entry, no cloud databases. Purely local, purely reliable.

Absolute Privacy

NoctRemote enforces a strict private-address firewall in code. Every outbound connection is blocked unless it falls within RFC 1918 ranges. Your commands go to your TV — nowhere else.

The NoctRemote Overlay Experience

Glass physics.
Native precision.

NoctRemote doesn't draw a UI on top of your OS — it extends it. The floating overlay bubble feels like hardware because it obeys the same physical laws as the system it lives inside.

Fluid Container Morphs

The overlay bubble morphs into the full remote panel in a single continuous animation — one window, one compositor layer, zero flicker.

Kinetic Fling Physics

Drag the overlay bubble anywhere on screen and release — it snaps to the nearest edge with natural deceleration, just like a first-party system widget.

True Native Glassmorphism

Real blur-behind using Android's FLAG_BLUR_BEHIND and RenderEffect APIs — not a fake frosted PNG. The background content actually blurs.

Multi-Device Switcher

Swipe the header to cycle between paired TVs with an animated name slide and dot indicators — premium UX without opening the app.
